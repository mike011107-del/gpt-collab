# LOGO 修改與驗收

用於現有圖形標修訂。先讀[目前需求](目前需求.md)及[決策與退稿](決策與退稿.md)。依據：梁特助 11-10 修改單、原參照圖，以及 PR #56–#66 的協作紀錄。PR #68 的最新兩版要求優先；#67、#68 實作數值另列紀錄。這份文件列檢查方法，不宣稱任何現存稿已通過。

## 先固定母稿

記原圖檔名、版本、SHA-256、畫布與可見圖形邊界。確認本次是同心弧款或葉片式款，兩版共用水管、接頭、建築及整體尺寸。只有 PNG 時，向量重建要明標，不能說是原 SVG。母稿未取得時，先完成資料與規格核對，不冒用十一版或退稿版當現行母稿。

原圖、修改圖以同尺度對照，不各自拉伸塞進同一框。整體、局部及縮圖使用同一輸出版本，局部放大須來自該稿，不能另畫示意冒充。

## 逐項核對

| 項目 | 製圖與畫面要求 | 交件證據 |
|---|---|---|
| 建築 | 三棟相連、中央高，暗面左後側；左樓前、右樓後，右暗面只露窄條；無突兀橫槓，無立面裝飾線 | 原稿同尺度疊圖、遮擋關係與屋頂局部 |
| 屋頂與直線 | 沿原稿前角向兩側斜下，三棟相同組斜率；垂直邊直立，照原稿黑白面關係 | 端點／斜率數值及實圖；不換成另套透視風格 |
| 同心同傾 | 管與光圈各層使用同一中心及傾角，對應橢圓；同層線寬一致 | 各層中心、軸向、線寬或輪廓量測；量測法與單位 |
| 線型光圈 | 依線型原參照安排外粗內細、長短弧與開口。維持鏡頭的層次，避免機械式增加平行軌道 | 原參照與修改圖並排，分別查層間白縫、斷口、跨層開口與樓邊白縫 |
| 斷口 | 同一套斜切規則，完整無缺角、尖刺、毛邊；最外層光圈保留空白 | 真正輸出稿的斷口放大圖；不要只列段數 |
| 葉片式款 | 分隔線切到同一內橢圓、間隙等寬，原參照可見七條；分清被建築遮住與實際刪除 | 逐條標起終點與角度差；第十七版八片等分是作者做法，須對原圖查偏差，不能只靠等角宣稱已驗收 |
| 管身 | 純黑實心、連續，沿原橢圓，後段自然被樓遮擋，前段與後段連得上 | 遮擋前完整幾何路徑與實際輸出；不能在樓側突變軌跡 |
| 接頭 | 小型俐落的直角套管方向，緊貼管身，保有沖吸車專業管件識別；三處依各自管線方向放置 | 原管件參照、三處局部與縮圖。避免白線切斷管身、月牙、大法蘭、凸肋或唇環舊試案 |
| 留白 | 樓和光圈間白縫一致，樓間相接不加白縫，無零碎殘段 | 樓邊與開口局部、縮圖；增加留白不等於一律減細黑線 |
| 細節 | 無灰線、碎片、孤立尖角、漸層、反光、投影、文字 | 高解析放大、單色與反白目視 |

線型光圈是使用者指定的視覺意象，不能聲稱它是真實機械光圈的活動結構。七段款的幾何一致也只證明圖上關係，不等同已驗證機械運作。

第十八版同心弧使用兩層與垂直斷口，但這是製圖紀錄；原修改單的斜切規則保留作差異檢查。方向獲確認不表示所有改法獲准。七段款的舊比例要求亦保留在下表追溯，兩版共用建築時不可默默套用不同樓寬。

## 比例分開量

| 量測 | 目標／狀態 | 定義 |
|---|---|---|
| 樓群寬／外管寬 | 約 0.618 | 樓群可見外緣與管身外緣的水平寬，接頭凸出另列 |
| 主樓正面寬:高 | 線型及七段寬版約 1:2.25 | 排除左後暗面；用圖上標記說明高的上下端點。側面與斜頂不可混進分母 |
| 七段另一比例 | 約 1:2.618，待選方案 | 與寬版分開編號，不自動取代線型主樓 |
| 整體可見外框寬:高 | 梁特助要求黃金比例構圖，仍須實驗收 | 含接頭的黑色圖形外框，不含白色畫布。另列不含接頭數值及與 1.618 的差異 |

標記實際端點、單位、計算結果、目標與差值。不得把畫布比例、線寬級數、黃金角或單一比值稱為「整體已符合黃金比例」。不得為逼近外框值壓矮主樓、拉扁光圈或令樓群失去原占比。若目標彼此牽動，交出原比例與微調差異，保留未滿足項，不自行取消要求。

## 交件檢查

- 交原稿對照、修改圖、高解析白底、可編輯 SVG，以及交辦要求的透明／反白版。PNG 與 SVG 輪廓一致。
- 實際查看全圖、三接頭、斷口、樓後遮擋及樓圈白縫。黑白反轉不能令建築的前後關係失真。
- 以使用位置測縮圖。可先檢 96／48／24 px 及 15 mm 印刷尺寸作診斷，標明這是測試尺寸，非已核定最小尺寸。螢幕模擬不能代替實際印刷。
- 每項記「符合／不符合／未測／不適用」及證據，不先把表全部勾過。無法辨識光圈或接頭、建築變形、選錯母稿都要先修。
- 交件寫清楚變更、實際檢查、仍未解決處。商標檢索、權利判斷、實材與受眾識別需各自證據，不由本表代為通過。
