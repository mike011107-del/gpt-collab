# 圖面交辦與驗收

梁特助 10-21 06:23 UTC：「接下來由你主導，AutoIP與GPT負責產出圖面」。Claude 負責想清楚要什麼圖、交辦、驗收、整理；畫圖交給 AutoIP 與 GPT。決定權仍在梁特助。

## 誰畫什麼

| 工作 | 交給 | 理由 |
|---|---|---|
| 空白場景（辦公室、招牌、文件、車旁環境），要精準色 | AutoIP 生空白場景，Claude 用 `scripts/recolour.py` 貼色 | 提示詞寫色號會畫錯（10-16 實測 ΔE_ok 0.06–0.20）；程式貼色保留原圖光影，色號由程式決定 |
| 氛圍圖、不需要精準色的場景 | AutoIP 文生圖或以圖生圖（強度 0.25–0.45 不跑色） | 便宜：文生圖 10 點、以圖生圖 15 點 |
| 多頁提案、排版 PDF、HTML 版面 | GPT 代理（開「給 GPT」Issue） | GPT 10-20 交過 24 頁完整排版 PDF |
| OpenAI 生圖模型（gpt-image-2 等，這個雲端環境可直接呼叫） | Claude 直接呼叫 | **10-21 只確認模型清單讀得到，還沒實測生圖。第一次用前先問梁特助費用**（記在他的 OpenAI 帳號） |
| 色號、對比、色差、取色 | Claude 用 `colour-tool` | 數字不交給生圖模型 |
| logo、標準字 | 不交給生圖模型 | 要原創字形（10-11 梁特助要求），AI 生成有相似與版權風險 |

## 開工

1. 查 AutoIP 餘額（不扣點）：`curl -sS -A "songchun-ci/1.0" -H "Authorization: Bearer $AUTOIP_API_KEY" https://autoip.app/api/v1/credits/balance`。要自訂 User-Agent，Python 預設 UA 會被 Cloudflare 擋（1010）。10-21 可用 3084 點。
2. 先看已有的底圖，能用就不重生：`/mnt/project-files/AutoIP串接/學習_20261016/out/e3_*.png`（招牌、接待台、文件、文具）、業主報告用過的 `崧淳CI/業主報告_20261020/原始檔/i/fascia_*.jpg`。
3. 查 GPT 有沒有已交的圖（gpt-collab 與梁特助電腦崧淳資料夾，見 `gpt-collab-routine`）。

## 交辦單（AutoIP 提示詞與「給 GPT」Issue 都照這個寫）

```
目的：這張圖要讓誰看懂什麼（一句話）
用在哪：業主報告第幾頁／提案板／簡報
尺寸與格式：例如 1600×1000 PNG、A4 直式 PDF
固定內容：文字逐字列出；色號用 HEX（主色、工程黃 #D68702、白、墨色）
可以變的：構圖、角度、光線
不要：logo、亂碼字、米色底 #F4F1EA、過度乾淨的塑膠感、葉片水滴等同業擁擠圖形
驗收條件：例如「貼色區 ΔE00 ≤ 1」「全名 12 字逐字正確」「標示『示意』」
交件位置：gpt-collab 交件/GPT/日期_主題/（不含第三方照片），或梁特助電腦崧淳資料夾新資料夾＋在 Issue 留路徑
```

- AutoIP 提示詞用英文，寫行業細節去 AI 感（管網圖、管內攝影畫面、磨石地、日光燈、工地圍籬），結尾加 `no text, no logo, blank white surface`。
- 給 GPT 的 Issue 標題開頭「給 GPT」，只寫一件事；它覺得交辦有錯可以直接回。

## AutoIP 生圖步驟

1. 先生 1 張試，看圖再批次。程式：`交件/Claude/20261016_AutoIP協同學習/程式/autoip_text_to_image.py`（單張）、`autoip_batch.py`（批次）；金鑰只從環境變數讀，不寫進檔案。
2. 要精準色的面，做規格檔後跑 `python3 -I .claude/skills/cis-visual-direction/scripts/recolour.py 規格.json`。`src`、`out` 路徑以執行時的目錄為準，建議寫絕對路徑。
3. 用 `colour-tool` 的 `image` 取貼色區代表色，跟目標色算 ΔE2000，寫進交件說明。
4. 記下用了幾點。

## 驗收（交給梁特助前每張都過）

- [ ] 實際打開圖看過（Read 圖檔或 render 成 PNG）。沒看到就寫「未目視」。
- [ ] 色號與交辦單一致；貼色區 ΔE2000 有量。
- [ ] 文字逐字對（全名「崧淳環保科技股份有限公司」、工項「污水下水道清淤」「CCTV檢視」）。生圖模型畫出的中文字一律不採用，字由程式或排版疊上。
- [ ] 沒有 AI 感跡象：米色底、塑膠光、對稱過頭的空場景、假文字、怪手指。
- [ ] AI 生成或貼色的場景標「示意」；車身與招牌色號註明是螢幕色，不是烤漆或印刷色。
- [ ] 一個標誌只放一個構成想法；16px 縮小、單色、反白都看過（美感串 PR #32）。
- [ ] 交件用白底。
- [ ] 第三方照片、業主報告 PDF 不推 gpt-collab（公開庫）；放專案資料夾與梁特助電腦。
- [ ] 業主要看的報告做成有色塊與照片的 PDF（梁特助 10-17、10-20 都要求）；另存新檔，不覆寫舊檔。

## 收 GPT 交件

- GPT 的圖是參考資料，不是決定。驗收照上面清單；色號重算、文字逐字核對。
- 有問題在同一個 Issue 回，列「讀到的檔、做了哪些檢查、發現、下一步」，結尾加 Claude Code 署名。
- 不改 `交件/GPT/` 的檔；要修就在 `交件/Claude/` 另存。

## 不要做

- 不讓生圖模型決定色號，也不拿生圖結果當色彩證據。
- 不替被否決的方向換包裝重交（Claude 配色 16 輪都被否，見專案記憶）。
- 不把負責人出生或命理資料、第三方受版權圖當生圖輸入送出去。
- 不答應自動續跑或定時交件；用量上限撞到就停，要等梁特助下一則訊息。
