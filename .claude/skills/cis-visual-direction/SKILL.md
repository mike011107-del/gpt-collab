# 圖面交辦與驗收

需求與色號只從協作/目前需求.md 取得。依協作/工作方式.md 交辦，LOGO 加讀協作/LOGO修改與驗收.md。本檔不固定色號、餘額、API 價格或永久工具可用性。

| 任務 | 做法 |
|---|---|
| 原稿局部修訂 | 固定母稿及修改區，優先可編輯原件；不得整張重生後聲稱原結構未動 |
| 新構想探索 | 梁特助有要求才做；區分構成差異，不以換色或換名字湊方向 |
| 精準配色與文字 | 由可核對的向量或排版流程處理，輸出後量測色碼並逐字核對 |
| 場景、應用示意 | 當次交辦要求才做，標明示意，第三方素材依授權處理 |

交辦寫清楚用途、尺寸、原圖版本與雜湊、固定元素、可改範圍、需要的輸出和驗收證據。圖形標不放文字；其他文件如需公司全名，逐字核對「崧淳環保科技股份有限公司」。

工具以當次環境能力和授權為準。AutoIP 網頁與 API 分開，歷史內容審查／費用紀錄不當作新授權；禁止為克服拒絕反覆換入口送出。不能自動檢查餘額、生成付費圖片或外送私有稿。

交件前實際看圖、查原稿差異與適用規格。測量只能支持測到的部分；效果與美感依同尺度實圖判斷，業主採用另記。
