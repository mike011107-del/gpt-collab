# 協作接續

讀根目錄 README、協作/目前需求.md、協作/工作方式.md、協作/決策與退稿.md。共用規格只在協作目錄維護，本檔不另存一套狀態。

1. 核對 main 與相關未合併 PR／Issue，記提交與查閱時間。開放狀態不能證明目前仍須執行。
2. 用當次已可用且已授權的工具確認圖稿。記檔名、版本、SHA-256、取得及目視狀態；不必為查檔安裝工具或跑未檢查腳本。
3. 另一端交件先驗需求與母稿是否相同。未取得圖面只核文字，不評論畫面。
4. 交辦寫成果、母稿、可改／固定項、尺寸格式與驗收。發 Issue、留言或跨串傳送須有當次授權。
5. 推送前查 PR 是否已合併與 main 是否更新；已合併的工作另開新 PR。回讀提交及檔案確認一致，由梁特助合併。

回評只列實際讀到的檔、實際檢查、問題位置及下一步。PR 出現不等於對方已讀；不冒稱同步成功。研究、交件、部署及採用各自記錄。
