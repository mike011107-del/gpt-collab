## 二、已撤回或限縮的問法

### 原第6題：應用場景選擇撤回

GPT在三色尚未收斂時，先問白底文件、招牌／制服或兩者並列。梁特助指出時序不當，GPT已撤回。**本輪沒有選出主要應用場景，也沒有把三者中的任何一項記為梁特助決定。** 後續改先確認三色本身。

### 第8題：不得以三類清單限制研究

GPT原先只列深藍、深青、深綠，梁特助在這份清單內選了「三類並列」，隨後明確質疑為何默認這幾類。GPT已承認是自行縮小範圍，並撤回其限制。

因此不能把原選項內的回答當成「只研究這三類」或「三類等量就是已核定範圍」。這三類可以作示例或候選，但不構成排除其他符合條件冷色的理由；紫色另由第11題明確維持排除。

### 第9題：只採用外觀偏好，不恢復色系限制

第9題原問法也帶入三類前提，曾撤回。其後收到的答案為「深而有色感」。GPT隨即限定為主色外觀偏好，沒有恢復藍／青／綠限制。有效內容是「深、有清楚色感」，不是「這三種色系已被指定」。
