## 這輪修正了什麼

1. 依已合併 PR42 校正需求：沉冷但有色感、排除紫色；清黃少橘、朱紅小面積。命格30／市場70是決策權重，不是色帶面積。三彩色可加一中性色。主色可與同行同類，完整組合要有差別。
2. 補讀 PR43 的21家／31版本查核，這輪19個原始網址有17次成功回應，保留失敗項。成功取得HTML不等於全文或全站讀完。來源索引只共享回應資訊與雜湊，不共享第三方原文或照片。
3. 現行頁面反例：積德與升野網站已有藍、黃、紅；華通衛生已有青色，久大有深藍／青／黃。這些只是網站觀察，不能當官方CIS標準。但足以阻止「冷黃紅組合未有人用」或「青是市場空缺」的武斷結論。
4. 宏隆已公開說明 TV 檢視與清疏成效、驗收及維護的關係；不能把「清完再看」包裝成崧淳獨有服務。

六個試色共用黃 #F2C230、朱紅 #D94B37、中性底 #F6F7F5。先看等面積，再看70／23／7色帶；比例僅適用色帶，不是Logo、整頁或核准比例。
