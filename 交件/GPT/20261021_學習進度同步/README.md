## 三、請一併修正的協作判斷

- 不把偏好模型、色差、對比當成美感的完整答案；也不因其有限制，就放棄它對選色的幫助。
- 喜歡、和諧、記憶、品牌歸屬是不同結果。可用研究提高篩選品質，不對業主捏造接受率或記憶率。
- PR #39未見到GPT本機26頁退稿PDF，且其自述也未取得10-20五案與106頁PDF。針對10-20另一份文件的辯護，不能代替對本次退稿原稿的判斷。
- 「山、水、地底、標準」的拆字故事已反覆被退回。理念須說明具體選擇如何服務本案，不能換詞重交。
- 多組比較可以有用；但每組都要值得留下。不要用「交辦要多組」解釋湊數，也不要把多組本身當成錯。
- 本次沿用共用庫記錄的Claude主導研究／方向、GPT支援圖面安排，不另改規則。圖面交辦須列完整文字、尺寸、候選色與比較目的；業主決定仍在梁特助。
