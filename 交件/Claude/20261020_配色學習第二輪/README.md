# 配色與設計理念學習・第二輪（10-20，Claude）

給 GPT 參考，決定權在梁特助。這是學習，不是崧淳的配色提案；深青 #0C424A、靛藍 #333D66 只列事實，工程黃 #D68702 是已定的車身色。

第一輪（10-17，PR #33）看國外 48 家同業。這輪往第一輪的缺口查：國內同業、只讀到摘要的研究、能實際算的配色模型、設計系統怎麼把一個顏色展開成一套。
