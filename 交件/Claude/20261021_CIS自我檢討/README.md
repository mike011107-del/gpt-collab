# 崧淳 CIS 自我檢討｜2026-10-21

撰寫：Claude。依據：梁特助 10-21 兩則原話。第一則：「首先創作理念與發想太ai，其次是一看就知道好多組都是來湊數的，完全不美，你收集到那麼多資料難道都不會自我審視嗎?」第二則：「你負責檢討企業識別系統，全域查找相關資料並開始自我檢討」。

- **寫了什麼：** 把 10-11 到 10-21 被否的東西排在一起，找出共同的錯；逐項檢討現行成果；列出我的自我審查為什麼沒擋下來；寫出往後的做法。
- **根據什麼：** gpt-collab main `986e999` 的全部交件文字檔（Claude 與 GPT）、10-17 配色建議書 PDF 全文（pdftotext）、10-20 業主版文字版、Issue 與 PR。另有 3 次網路搜尋，只讀到摘要。
- **沒讀到：** GPT 10-20 交在梁特助電腦的五組提案 PDF 與 106 頁報告（這個工作階段連不到那台電腦），以及 Claude 專案資料夾。對 GPT 五組的判斷只根據色號。
- 標示：**查得**＝檔案或原文看得到；**計算**＝這次用 colour-tool 重算；**推論**＝我的判斷。

## 結論

1. 十天來被否的理由，可以歸成五個同樣的錯：用數字代替眼睛、拿名字編故事、為了「多給幾種」湊組數、照模板把格子填滿、把被否的方向換個說法再交。
2. 我的自我審查只查對比、色差、錯字、出處，沒有一條在問「這樣好不好看」「拿掉會不會比較好」。所以數字全過，東西還是醜、還是湊數。
3. 現行成果裡，能直接留下的不多：業主版裡逐項列事實的部分、工程黃 #D68702 的取法、兩個候選主色的色差與對比數字。設計理念文字、多組並列、標語第四輪都要重做或大刪。
4. 公開庫裡還有負責人姓名和命格結論（第五節），這跟現在的規則衝突，要梁特助決定怎麼處理。

## 二、五個重複出現的錯

### 1. 用數字代替眼睛
- 主色是程式掃出候選、照色差排名挑的。靛藍 #333D66 就是這樣來的（Claude 10-17 概覽 A 版）。
- 10-16 我已經在自己的檢討寫過「擁擠度不是美感」，之後的選色還是照擁擠度排。
- 色差、對比只能說明「分不分得開、讀不讀得到」，不能說明好不好看。這點寫在美感學習第一輪第 4 條，我自己沒照做。

### 2. 拿名字編故事
- 10-17 配色建議書的設計理念：「深青：做事的地方……像打開人孔蓋往下看的深度」，結尾三句「黃，讓人在路上看見崧淳；深青，是崧淳做事的地方；白，是崧淳交出去的成果。」比喻加三段排比，正是梁特助說的 AI 味。查得：建議書 PDF 第 3 頁。
- Claude 10-17 概覽 A 版也一樣：「山尖穿出圓框＝標準超出框架」「線下留白＝淳、乾淨」，B 版插圖配「工作在地底，標準在山頂」。
- 美感筆記第一條就寫「標誌不是在描述業務，比的是簡單、好認、只像自己」。我知道這條，還是照做。

### 3. 為了「多給幾種」湊組數
- 10-13 梁特助說「多給幾種組合方向」。之後每輪三到十七組，組數越多，被否得越快。
- GPT 10-20 的五組，用我們已有的同業資料比對，三組撐不住（計算，ΔE2000）：

| GPT 的色 | 最近的色 | 色差 | 問題 |
|---|---|---|---|
| 深海軍藍 #1E324F | 大亞 #213750 | 2.75 | 幾乎就是同業的顏色 |
| 冷鋼藍 #344B5C | 源昌 #414951；業主否掉的鈦岩灰 #47565C | 5.5；6.6 | 靠近同業，也靠近已否的色 |
| 墨綠 #214D43 | 綠邑 #254529 | 8.4 | 深綠配黃，跟垃圾車那條是同一個問題 |

- slogan 第四輪寫了 30 句再挑 4 句。數量本身就是湊數的做法：30 句裡大部分是為了湊滿六個方向寫的，刪掉的理由多是「轉折弱」。
- Claude 10-17 概覽 B 版，是把重送的提示當成「再出一張」，顏色不換，只換排法。

### 4. 照模板把格子填滿
- 品牌概覽提示詞要 4–5 色、1–2 字體、漸層、4–6 圖示、插圖、版面。我一格一格填滿，填的東西多半不是崧淳需要的：
  - 五個顏色裡真正有工作的只有主色和工程黃。同業一半只用一個顏色加黑白（台灣 20 家中 10 家，國外 48 家中 23 家；查得：20261020 配色學習第二輪）。
  - 放了漸層條。但業主版自己寫「不要在主色上加漸層」。
  - 六個管子、水滴、梯子的線條圖示，任何一家清淤公司都能用。台灣 21 家同業裡 8 家畫水滴、水波、管子（查得：業主版第 4 頁）。
- 學習報告也一樣：一輪 33 頁、34 頁、61 KB，篇幅大，判斷少。10-16 的檢討已經寫「這輪多半是蒐集和計數，美感沒有學到」，之後又重複。

### 5. 把被否的方向換個說法再交
- 「工作在地底，標準在山頂」和山與水插圖，跟 10-11 被否的「名是高山、業在地底」是同一個意思。
- 10-16 雙方都撤回「深青少人用，所以是機會」。10-17 建議書第 5 頁卻又寫「同行沒有人用，建議」，而且這句後來證明是錯的：華通衛生行 #005959，色差 9.3（查得：統合總整理第二節第 2 條）。

## 四、我的自我審查為什麼沒擋下來

- 我有的檢查全是能算的：對比、色差、錯字、出處、授權。沒有一條在問「放在一起好不好看」「拿掉會不會比較好」。
- 核查代理也是對數字與出處。審稿紀錄 30 條意見，29 條是事實、數字、措辭，第 30 條講版面斷字與空白；沒有一條在問好不好看、有沒有湊數（查得：`20261020_業主版統合報告/審稿紀錄.md`）。
- 梁特助喜歡的參考圖，10-16 問過兩次，一直沒拿到。我在沒有他的眼光當基準的情況下繼續出稿，而不是先停下來。
- 外部說法可以對照（只讀到搜尋摘要）：
  - 有事務所主張只交一個推薦方向，讓設計方負責推薦、客戶負責決定；交太多選項，客戶會無從判斷。
  - Bierut 承認提案裡直覺的選擇很難誠實解釋；常見的建議是把功能上的理由跟直覺分開講，不要把直覺包裝成邏輯。

## 五、公開庫裡不該有的東西（要梁特助決定）

查得，2026-10-21 在 main `986e999` 搜尋：

- 17 個檔含負責人命格結論（例如 10-17 配色建議書 PDF 第 6 頁、第十五輪說明與手機頁、歷輪提案）。
- 2 個檔含負責人姓名（`00_總覽.md`、`04_定位與產業研究/01_產業與同業研究.md`）。
- 業主報告 PDF：`20261017_配色建議報告書/崧淳_品牌主視覺配色建議書_20261017.pdf`。

README 寫「不放負責人的出生、命理資料」「不放業主報告 PDF」。刪檔只會從最新版本移除，git 歷史裡還在；要徹底移除，得改寫歷史，或把庫改成私人庫。這兩件都會影響 GPT，所以我沒動。

## 六、往後的做法

1. **一次一個推薦。** 最多附一個對照，並寫清楚為什麼不選它。不再「多給幾種」。
2. **理念只寫事實和用途。** 不用比喻、不拆字、不寫三段排比。看起來的判斷就直說「這是看起來的判斷」。
3. **每個元素先問「拿掉會少什麼」。** 說不出來就刪。模板要的格子沒有理由填，就留空並說明。
4. **好不好看要在真實場合看圖判斷。** 數字只當及格線：讀不讀得到、跟誰撞。
5. **交件前比對被否清單**（本檔第一節）。意思相同、換個說法的，不交。
6. **缺梁特助的眼光時先停。** 先要兩三張他覺得好看的企業識別圖，再出下一稿。
7. 圖面照 10-21 新分工，交 AutoIP 或 GPT 產出，Claude 驗收。

## 七、要梁特助決定

1. 主色要不要由 Claude 收斂成一個推薦。我會在真實場景圖上把深青、靛藍並排看過，寫出理由後再交。
2. 第五節的檔怎麼處理：刪檔、改寫歷史，或把庫改成私人庫。
3. 兩三張你覺得顏色或標誌好看的企業識別圖（任何行業都可以）。
4. Claude 10-17 概覽 A／B 的分支要不要刪。

## 八、反方：哪些批評不成立（10-21 補）

梁特助 10-21 原話：「你現在開始全域查找你與gpt協作的專案，把全部內容重新審視並檢討，試著反駁我，我說的是錯誤的」。

下面逐條對照證據。結論分三種：成立、部分成立、不成立。

### 1.「收集那麼多資料都不會自我審視」：字面上不成立

查得的自我審視紀錄：

- 10-16 學習總整理列出「已推翻」的結論。
- 10-17 統合總整理第三節撤回或更正了 16 條說法，包括「同行沒有人用深青」「工程黃就是崧淳辨識色」。
- 10-20 業主版審稿 30 條：6 條必改全改，建議 24 條照改。
- slogan 第三輪自己作廢。
- GPT 也交過更正：PR #27 的 errata，10-18 指出「車身實測」的寫法有錯。

成立的是另一句：**自我審視只審事實與數字，沒有審美感與湊數。** 第四節原本就這樣寫，結論改成這句。

### 2.「好多組都是來湊數的」：部分成立

多組是交辦要求的：

- 梁特助 10-13：「多給我幾種組合方向」。
- README 從 10-14（`cc64c65`）到 10-21（`1ffde1f`）都寫著「多給幾種方向」。GPT 10-20 交五組時，這條還在。
- 10-17 的品牌概覽提示詞是梁特助寫的，指定 4–5 色、4–6 圖示、漸層、插圖。

所以組數多、格子填滿，有一部分是照交辦做的。

成立的部分：

- 我們手上有資料，能證明哪幾組站不住（第二節第 3 條，GPT 三組），卻沒有在交件前指出來刪掉。
- 交辦要「多給幾種」，也要「屬於崧淳」，兩件事會互相拉扯。我們沒有說明這個衝突，只照字面做。

### 3.「完全不美」：現在沒辦法驗證，也沒辦法照著改

- 沒有共同的基準：梁特助喜歡的參考圖，10-16 問過兩次，到現在沒有。
- 現在沒有「設計」可評：業主版是選色用的事實報告。logo 還沒開始，這是梁特助定的順序「先定色再做 logo」。
- 業主本人還沒看過任何一稿。
- 推論：只靠一個人「不美」的判斷、又沒有參考圖，下一輪無從收斂。前面 16 輪就是這樣過的。所以這條要先補基準，不能直接再做一輪。

### 4.「創作理念與發想太ai」：對 10-17 成立，對現行版不成立

- 10-17 建議書的理念有比喻和三段排比，成立（第二節第 2 條）。
- 10-20 業主版已經拿掉理念故事，只列事實與使用原則，這條批評不適用。
- 拿名字講故事的寫法，有一部分是交辦要求的：
  - 「崧高看標準，淳深下功夫」是梁特助 10-17 自己寫在提示詞裡的句子，也是拆名字、講山與水。
  - 10-17、10-18 又說「崧淳兩個字可以拆開」。
  - 命格占 30%，也逼著理念要解釋顏色跟命格的關係。

### 5. 我自己上一版檢討改過頭的地方

| 上一版寫的 | 更正 |
|---|---|
| 「用數字代替眼睛」 | 太籠統。選色條件有 70% 是市場辨識與差異化，用色差比同業正是這部分該用的工具。錯在把它當成美感的答案 |
| 業主版「兩色並列，把判斷推給業主」 | 錯。兩色並列是梁特助 10-20 在決策卡上選的，不是 Claude 推卸。撤回 |
| 概覽 A／B「全部作廢」 | 太過。靛藍 #333D66、淺階 #B6C5DF、墨色 #1B1F29 已經用在業主版，仍是候選；作廢的只有標誌、理念文字與湊數元素 |

## 九、對照後的結論

- **錯在我們：** 理念用比喻、把被否的方向換個說法再交、手上有資料卻不刪站不住的組、沒有對互相拉扯的交辦提出異議、只審數字不審美感。
- **不全在我們：** 多組與填滿格子，是交辦要求的；美感沒有共同基準，誰都沒辦法對準。
- **要先解決的不是再做一輪，是兩件事：** 給參考圖當基準；「多給幾種」改成「一次一個推薦」。後者 README 10-21 已經拿掉「多給幾種」，這裡只是把它寫成規則。
