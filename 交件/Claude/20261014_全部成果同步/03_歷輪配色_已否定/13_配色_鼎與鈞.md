# 崧淳配色：鼎與鈞（第十二版）

2026-10-12（UTC）。這一版不沿用第十一版的定位、配色和宣傳語，改從崧淳自己的素材找核心：負責人名字、你們上一份品牌提案、公司名、車隊。

## 核心

- 負責人名字裡的「鼎」和「鈞」，就是崧淳的核心。你們上一份提案的「以鼎立信任，以鈞衡精度」，這個方向不變，顏色全部重來。
- 鼎：一言九鼎，說出口就算數。鈞：古時候秤重的單位，三十斤是一鈞。
- 放到清淤：答應的做到，清了多少秤給你看。

## 五組配色

### 1. 鈞天黃（暖）

明黃 #F9D71C、宮紅 #A61C24、白 #FFFFFF

「崧」是中嶽嵩山；「鈞」在古書裡指天的正中央（《呂氏春秋》：「中央曰鈞天」）。
公司名和負責人的名字都指向正中央，中央的顏色是黃。現在的黃色車隊剛好接得上。

命格：黃屬土、紅屬火，都是負責人喜用的。

這個黃比之前命理建議的琥珀黃更亮、偏檸檬。

### 2. 鈞窯紅（暖）

鈞紅 #A92A2D、白 #FFFFFF、天青 #A9C9D6

「鈞」也是宋代五大名窯裡的鈞窯。鈞瓷的紅，是釉裡的銅在窯火裡燒出來的，每一件都不一樣。
深紅當主色，留一小塊鈞瓷常見的天青。

命格：紅屬火，是喜用；天青帶水，只用一小塊。

### 3. 青銅（冷）

銅綠 #3E9E8C、白 #FFFFFF、墨 #181614

鼎是青銅鑄的。青銅剛鑄好是金黃色，放久了表面長出一層綠，才被叫作「青銅」。
這層綠要很多年才長得出來，用來說崧淳要做得久。

命格：銅綠屬木，三個命理版本說法不一；墨屬水，只用在字上。

### 4. 銘文（中性）

白 #FFFFFF、墨 #181614、印紅 #C8323C

古人把重要的事鑄在鼎上，改不掉，誰都看得到。
崧淳的紀錄也照這個做：白紙黑字，最後蓋一個紅印。

命格：白屬金、墨屬水、紅屬火；水的部分只在字上。

同行邦盛的字標也是黑配紅，這組要靠白底和印章的樣子拉開。

### 5. 秤星（中性）

秤桿 #5E2A20、秤星白 #FFFFFF

「鈞」是秤重的單位。老秤桿上有十六顆星，老一輩說，少給一兩損福，二兩損祿，三兩損壽。
深木色的秤桿配白色秤星：清多少，就是多少。

命格：深木色屬土，是負責人喜用的。

## 我替你做的判斷

- 核心改用負責人名字裡的鼎和鈞。你們上一份提案的方向（以鼎立信任，以鈞衡精度）你沒有否定，否定的是那份的顏色；所以方向留下，顏色全部重來。
- 五組的主色各不相同：黃、紅、銅綠、白、深木色。冷色一組（青銅），中性兩組（銘文、秤星），暖色兩組。
- 避開了：你們上一份提案的五色、命理建議的三色（琥珀黃、深焙褐、赭紅）、第十一版用過的顏色、紫色，也避開交通錐的橘紅。
- 淺藍、粉紅、橘色沒有放：淺藍同行森淨家已經在用；粉紅是第十一版的方向；橘色太像交通錐和工地。
- 名片示意的姓名欄留空，電話、地址待補。字型用現成字型示意，不是之後要做的原創字。
- 車身是想像圖，用來看顏色放在車上的樣子；現有黃車不必重漆。

## 出處

- 「中央曰鈞天」：《呂氏春秋・有始覽》。
- 「崧」指中嶽：《康熙字典》引《通雅》「今之中嶽名崧」。
- 一言九鼎：出自《史記・平原君虞卿列傳》「使趙重於九鼎大呂」。
- 鈞為三十斤：《說文解字》「鈞，三十斤也」。
- 鈞窯為宋代五大名窯之一，紅色窯變來自釉中的銅。
- 秤桿十六星（北斗七星、南斗六星、福祿壽三星）與「少一兩損福」是民間流傳的說法，不是史料。
