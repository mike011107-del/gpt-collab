# 企業識別系統（CIS）包含什麼

查找日：2026-10-11
範圍：網路搜尋 2 次，讀了 3 個頁面全文。也搜尋了 Drive，沒有找到 CI 相關參考檔。
標記方式：【查得】表示有來源原文支持；【慣例】表示業界常見做法，但上面 3 個來源沒有逐項列出。

## 一、三層架構【查得】

| 層 | 內容 | 來源 |
|---|---|---|
| MI 理念識別 | 核心層：企業個性、文化、價值觀、經營理念 | 雷鳥設計 |
| BI 行為識別 | 把理念落實成行動。對內有員工訓練，對外有促銷、公益活動、市場調查 | 雷鳥設計 |
| VI 視覺識別 | 結合 MI 與 BI 的具體形象：名稱、Logo、顏色、圖形、吉祥物，並延伸到產品、包裝、廣告 | 雷鳥設計；東海大學列出了三層的名稱 |

## 二、VI 基礎系統

| 項目 | 依據 | 我們做得到嗎 |
|---|---|---|
| 標誌（Logo），含直式、橫式等組合 | 【查得】三個來源都有 | 可以，用 SVG 向量繪製 |
| 標準字（中英文公司名的字形） | 【查得】 | 可以。目前中文字型只有一套，要做得好需要你提供授權字型 |
| 標準色與輔助色，含印刷用與螢幕用色碼 | 【查得】aytm 列出主色、次色、第三色 | 可以給出色值；印刷實際顏色需要打樣確認 |
| 指定字型（標題、內文、線上、線下） | 【查得】aytm | 規範可以寫；字型檔本身要你提供 |
| 輔助圖形與圖像系統 | 【查得】東海大學 | 可以做幾何類圖形；做不了攝影風格的圖 |
| 最小尺寸、淨空區、擺放位置 | 【查得】aytm | 可以 |
| 錯誤使用示範（不可以怎麼用） | 【查得】aytm | 可以 |
| 商標與智慧財產標示（®、™） | 【查得】aytm | 標示規範可以寫；商標檢索要人工查 |
| 吉祥物 | 【查得】雷鳥設計列在 VI 之下 | 只能做簡單造型；精緻插畫做不到 |

## 三、VI 應用系統

| 項目 | 依據 | 我們做得到嗎 |
|---|---|---|
| 名片、信封、信紙、資料夾 | 【查得】東海大學、雷鳥設計、aytm | 可以 |
| 簡報範本 | 【查得】東海大學、aytm | 可以，產出 pptx |
| 制服、帽子 | 【查得】雷鳥設計 | 可以做平面示意；做不到擬真的穿著效果 |
| 產品、包裝、廣告 | 【查得】雷鳥設計 | 可以做平面版型 |
| 版型網格與尺寸範本 | 【查得】aytm | 可以 |
| 招牌、車體、展場、官網、社群頭像 | 【慣例】 | 可以做平面示意 |
| 電子郵件簽名檔、發票與報價單版頭 | 【慣例】 | 可以 |

## 四、交付形式

- CI 手冊（CIS Manual）：把以上規範集中成一份文件【查得】東海大學
- 品牌語氣與文字風格指引【查得】aytm，屬於 MI 延伸到對外溝通的部分
- 原始檔包（AI、SVG、PNG、PDF 各尺寸）【慣例】。SVG、PNG、PDF 做得到；.ai 檔需要 Adobe

## 五、我們的範圍判斷（推論）

- 做得到：MI 文字整理、VI 基礎系統、大部分應用系統的平面版本，以及 CI 手冊
- 需要外部支援：授權字型、擬真示意圖、商標檢索、印刷打樣
- BI 是組織行為面的規劃，只能寫成建議，需要由公司實際執行
