# CI 工作資源查找結果

查找日：2026-10-11　範圍：Claude skills、外掛、連接器、開源字型、向量與配色工具、商標檢索。
本輪只查找與核對，**未安裝、未下載、未執行任何第三方程式**。
授權欄標「已核對」者，是直接讀了該專案的原始授權檔；標「未核對」者只看到摘要或沒查。

## 一、結論

1. **最大的變化：Adobe 與 Canva 現在都已連上**（ListConnectors 回報 connected、本對話可用）。Adobe 有「點陣轉向量」與字型推薦，補上先前「無自動描圖」的缺口。功能本身尚未實測。
2. **開源字型現在拿得到。** GitHub 原始檔網址（raw.githubusercontent.com）這次可連線，先前盤點寫的「GitHub 403、只有文泉驛正黑」已不成立（網頁版 github.com 與 GitHub API 仍被擋）。實際下載字型檔尚未測試。
3. **Anthropic 官方 skills 庫沒有能直接做 CI 的現成品。** 它的 brand-guidelines 是 Anthropic 自己的品牌規範，用途是當範本：選色定案後，可以照它的格式做一個「崧淳品牌規範」skill，以後所有產出自動套用。
4. **商標檢索仍是缺口。** 智慧局商標檢索系統從這裡連不上，要用你電腦的瀏覽器查。

## 四、不建議

| 資源 | 理由 |
|---|---|
| AI Logo Maker & Brand Designer 外掛（ManyMotions） | AI 生成 logo，與「非文字產物不帶 AI 感」的偏好衝突；需註冊第三方帳號；社群級 |
| AdWhispr、Hyper Marketing 外掛 | 廣告投放工具，與 CI 無關 |
| Anthropic 的 canvas-design、theme-factory、algorithmic-art | 官方 README 說這些範例 skill 已內建於 claude.ai 付費方案；內容偏海報藝術與主題套用，不針對 CI |
