# 企業識別系統｜工具盤點

盤點日：2026-10-11　依據：本 thread 實際呼叫與實測（Claude 雲端執行環境）。
其他表面（CLI、手機 App）的能力不在此範圍，不可互相推論。

## 一、實測可用

| 工具 | 能做 | 做不到／限制 | 實測 |
|---|---|---|---|
| SVG 手寫向量（Python + cairosvg） | Logo 草案、標準字、輔助圖形，輸出 SVG／PNG／PDF | 不是 AI 繪圖，偏幾何、字標類；複雜插畫、手繪筆觸做不好 | 已實測：SVG 轉 PNG、PDF 成功，中文字正常 |
| ImageMagick | 點陣圖縮放、裁切、合成 | 這版無法直接讀 SVG（已改用 cairosvg） | 已實測 |
| python-docx／python-pptx／reportlab | Word 版 CI 手冊、PPT 簡報、PDF 手冊 | 排版精緻度不及 InDesign | 模組可載入 |
| LibreOffice、pandoc | docx 轉 PDF、Markdown 轉 docx | — | 已實測轉檔成功 |
| pip 安裝套件 | 可補 fonttools、opencv 等 | — | 已實測可下載 |
| Artifact 網頁 | 「Design System」類型：色票、字級、元件、Logo 用法的線上規範；「Slides」：簡報；「Design」：名片、信紙等應用物模擬 | 需要對外分享時才發佈，預設私人 | 類型清單已列出 |
| Claude Docs | 可共同編輯的 CI 手冊文字版、策略文件 | — | 連接器在 |
| Google Drive | 搜尋、讀取 PDF／圖片／文件；可新增檔案 | 新增屬外部動作，每次先跟你確認；不覆寫既有檔 | 讀取已實測 |
| Gmail | 搜尋、讀取往來信件找素材 | 寄信屬 A 級，不會自行寄出 | 讀取已實測 |

## 二、缺口

| 缺口 | 影響 | 補法 |
|---|---|---|
| 字型下載被網路封鎖（Google Fonts、GitHub 均 403） | 中文只有「文泉驛正黑」一套；思源黑體、思源宋體、商用字型都拿不到 | 你把授權字型檔（.otf/.ttf）上傳到這裡或 Drive，我就能用 |
| 沒有 AI 圖像生成 | 無法產出擬真情境圖、攝影風格示意 | 用 Canva 或 Adobe 連接器補，或由設計師提供 |
| 沒有向量描圖工具（未裝 potrace） | 現有 AIW_logo.jpg 只能「重繪」成向量，不能自動描邊 | 可嘗試安裝，未實測；最好仍是拿原廠向量檔 |
| Canva 連接器登入過期 | 無法用 Canva 範本與匯出 | 到 claude.ai「設定 > 連接器」重新連線 |
| 無 Adobe、Figma 連接器 | 無法直接產出 .ai 檔或進 Figma | 需要再接；Adobe 較貼近 CI 工作 |
| 無法做商標檢索 | 不能確認名稱或圖形是否撞商標 | 需人工查智慧局商標檢索系統 |
| 色彩只能給數值 | 可給 HEX／RGB／CMYK 換算與 Pantone 近似，無法實際打樣校色 | 印刷前請印刷廠打樣 |

## 三、建議的產出組合

1. Logo 與標準字：SVG 向量（可給設計師在 Illustrator 打開續修）
2. 規範：Design System 網頁（線上查閱）＋ PDF 或 Word 版 CI 手冊（交付、列印）
3. 應用物：名片、信紙、信封、簡報母片（pptx）
4. 提案：Slides 簡報，比較 2–3 個方向
