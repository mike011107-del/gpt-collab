# 原創字形能力方案

日期：2026-10-11　依據：本 thread 實查（PyPI 套件資料、原始授權檔、justfont 文章、教育部字形檔說明）。
本輪仍未安裝、未下載任何東西。

## 一、結論

1. **原創的範圍，預設做「標準字」，不做整套字庫。** 整套中文字庫要上萬字，justfont 說至少要兩年（查得）。CI 實務上的原創字形是為公司名稱量身設計的字，預設範圍如下：
   - 全名「崧淳環保科技股份有限公司」12 字；
   - 簡稱「崧淳」；
   - 英文名與數字。
   做完後另外包成一個只含這些字的字型檔（OTF），可以直接打字使用。
2. **原創的做法：從骨架自己畫起，不描任何現有字型。** 坊間的筆畫資料庫（Make Me a Hanzi、hanzi-writer）是從文鼎字型抽出來的，用了就變成衍生作品，不能算原創，所以不用。教育部標準字形只拿來核對字形寫法對不對，不拿它的輪廓。
3. **要補的能力有四塊**：造字工具鏈、我自己寫的筆畫引擎、手寫轉向量、客觀品管。工具全部是寬鬆授權的開源套件，從這裡可以安裝（PyPI 已確認有提供），只差你同意。

## 二、四塊能力

### 1. 造字工具鏈（pip 安裝，約 12 個套件）

| 套件 | 用途 | 授權（PyPI 套件資料） |
|---|---|---|
| fonttools | 讀寫字型檔、輸出 OTF | MIT |
| skia-pathops、booleanOperations | 筆畫輪廓合併、去重疊 | BSD-3、MIT |
| ufoLib2、defcon | UFO 原始檔：設計師可用 Glyphs、FontLab 打開續修 | Apache-2.0、MIT |
| ufo2ft、fontmake | UFO 編譯成正式字型檔 | MIT、Apache-2.0 |
| drawbot-skia | 字形試排、輸出樣張 | Apache-2.0 |
| svgpathtools、shapely | 曲線運算、筆畫偏移 | MIT、BSD-3 |
| cairosvg | SVG 轉 PNG、PDF | LGPL-3.0（只當工具使用，不影響成品） |
| vtracer、opencv | 手寫稿掃描轉向量、去雜點 | MIT、Apache-2.0 |
| fontbakery | 字型檔規格檢查 | 授權欄位空白，未核對 |

FontForge（GPL）也可能可以從 Ubuntu 套件庫安裝，未實測，非必要。

### 2. 筆畫引擎（我自己寫，這是核心）

以前畫 logo 是一筆一筆手寫座標，字與字之間很難一致。新做法：

- 先定**骨架**：每一筆（橫、豎、撇、捺、點、鉤、挑）是一條中心線。
- 再定**筆畫參數**：粗細、橫豎粗細比、起筆與收筆形狀、轉角。全部字共用同一組參數。
- 程式依骨架加參數長出輪廓，再合併成字。

好處：改一個參數，12 個字一起變，粗細、氣質一定一致；也可以一次產出粗細不同的幾組給你比較。
因為骨架是從零畫的，每個字都是原創。

### 3. 手寫轉向量（給想要人味的方向）

由你、負責人或委託書法家在紙上寫公司名，拍照上傳。我用 Adobe 的點陣轉向量工具或 VTracer 轉成向量，再修成標準字。
- 優點：原創性最明確，完全沒有 AI 感。
- 限制：手寫稿的品質決定上限；Adobe 這項功能尚未實測。

### 4. 客觀品管（用數字檢查，不只靠眼睛）

依 justfont 的字體設計觀念（查得），每個字自動量：

| 指標 | 意思 | 用途 |
|---|---|---|
| 字面率 | 字的實際大小佔字框的比例 | 12 個字看起來要一樣大 |
| 重心 | 筆畫墨量的視覺中心高低 | justfont：重心要趨近一致，讀起來才舒服 |
| 中宮 | 字中心區域的筆畫疏密 | 緊顯古典穩重，鬆顯現代開闊 |
| 筆畫粗細一致性 | 同類筆畫的實際粗細誤差 | 避免有的字看起來比較黑 |
| 小尺寸試排 | 名片 8pt、車身大字、單色、反白 | justfont：小尺寸才會暴露的問題要印出來看 |

## 三、交付形式（標準字完成時）

- logo 用：SVG、PDF 向量檔
- 打字用：只含公司名用字的 OTF 字型檔
- 設計師續修用：UFO 原始檔
- 品管報告：上表各項數值與試排樣張

手冊內文（說明文字）仍需要一套完整字庫，原創做不到上萬字，內文才用開源字型（見 01_資源查找結果.md）。

## 四、順序與限制

- 依先前決定，**先定顏色，再做 logo 與標準字**。這次只建能力，用跟公司名無關的「永」字測試工具鏈（永字八法涵蓋八種基本筆畫），不先畫公司名。
- 能力建好後，我會把整套做法寫成一個 skill，第二間公司可以直接沿用。
- 教育部筆順網、異體字字典從這裡連不上，核對字形寫法時要用你電腦的瀏覽器。
- 原創字形的著作權保護範圍、是否另外申請商標，屬法律問題，本輪未查證。
