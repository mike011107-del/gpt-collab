## 主色怎麼選的

1. 排除：歷輪已否定的提案色、業主 PDF 提案色（#172E3A、#C09B58、#27786F、#F5F6F2、#47565C）、深青／水青區、紫色。
2. 條件：白字對比 ≥ 9.5，工程黃放在主色上 ≥ 3.4。
3. 用 OKLCH 掃描深色冷色區：明度 0.24–0.45，色相 140–185 和 226–286（186–225 屬深青／水青，不掃）。符合條件、離同業與歷輪色又較遠的有三區：
   - 深綠（含近黑）：近黑的看起來像黑，而且深綠＋黃容易聯想到垃圾車和宏隆；
   - 藍到靛藍：色相 268–278，R 值小於 G 值，不偏紫；
   - 色相 280 以上的靛藍：偏紫，紫色不考慮。
   
   取藍到靛藍。這一區（色相 255–285、明度 < 0.45）在歷輪資料裡只有同業與參考色，沒有提案色。
4. 用 `20261016_配色參考查找/工具/palette_check.py` 比對街頭與國外案例後，選 #333D66（OKLCH 0.371／0.072／272）。

## 取捨與限制

- 仍是藍色系。深藍＋黃在台灣容易聯想到中華電信、台電工程車（見 20261016 配色參考查找）。這次靠偏靛藍、降彩度拉開距離，沒有消除這個風險。
- 同業與街頭色碼多是從圖片取的近似值。ΔE 只說明螢幕上的距離，不代表市場辨識度。
- 負責人命格（README 的 30%）沒有納入。
- 標誌是示意稿，用 Noto Sans TC 700 排字，字距 0.055em 沿用 GPT 名稱先行研究稿。尚未查商標，也未做字形修整，正式字標需要另外設計。
- 圖示標籤是依服務項目與車隊照片（吸污車、管捲盤、人孔旁作業）推定的，未向業主確認。
- 字型授權讀的是 google/fonts 的 OFL.txt（SIL OFL 1.1），只有這一份來源。

## B 版（梁特助同日再次送出同一提示）

檔案：`概覽B.png`（3840×2160）、`概覽B.html`。

配色跟 A 版相同。另外查了鮮豔的藍（OKLCH 明度 0.40–0.53、彩度 0.12–0.21、色相 256–272）：最近的是國外同業 Interflow #003DA5 和小松 #283D99，ΔE 只有 5–7，沒有比靛藍更能跟同業拉開，所以沒換。

B 版改的是標誌做法和版面：

- 標誌改成名稱先行：「崧淳」字標，下面一條工程黃線，線長跟公司全名一樣；全名下面並列兩項服務。方向沿用 GPT 名稱先行研究稿（字距 0.055em、兩項服務同等清楚）。
- 縮寫：白底方塊放「崧」字加工程黃短線，給頭像和小尺寸用。
- 版面左側整欄用主色，可以看到主色大面積的樣子。
- 字體多一套 Noto Serif TC（思源宋體），只用在標語。
- 插圖用一條虛線連起山頂和管線，配上梁特助肯定過的「工作在地底，標準在山頂」。

試過但沒用：把「崧」上半的「山」塗成工程黃。看起來像王冠，而且「崧」是罕用字，拆色後容易被讀成「松」。

重算 B 版前，先把 Noto Serif TC 下載到 `概覽B.html` 同一資料夾（字型檔 16.8 MB，不放進專案庫）：

```bash
curl -sSfL -o 交件/Claude/20261017_品牌識別概覽/NotoSerifTC-wght.ttf "https://raw.githubusercontent.com/google/fonts/1d0e46c7933245c8180fe83e47917961c913bbdb/ofl/notoseriftc/NotoSerifTC%5Bwght%5D.ttf"
NODE_PATH=$(npm root -g) node .claude/skills/colour-tool/scripts/render.cjs 交件/Claude/20261017_品牌識別概覽/概覽B.html 概覽B.png 1920 2
```

用這份字型重算，跟 `概覽B.png` 逐像素相同。Noto Serif TC 的授權同樣讀 google/fonts 的 OFL.txt（SIL OFL 1.1）。
