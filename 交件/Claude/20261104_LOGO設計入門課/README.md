# LOGO 設計入門課（2026-11-04）

梁特助 11-04 要「把我當初學者，從最基礎開始…一步步教會我如何設計個好 LOGO，同時也教會我色彩的運用」。這份是 A5 教學 PDF，44 頁，13 堂課，每堂一個練習與完成標準。

檔案：`崧淳_LOGO設計入門課_20261104.pdf`；`原始檔/` 可重建（見 `原始檔/重建說明.txt`）。

## 結構

- 第一部 先懂 LOGO：1 LOGO 能做什麼、不能做什麼；2 七種類型與新公司怎麼選；3 一頁簡報、同行牆、查撞標
- 第二部 練形：4 剪影與 30 格草圖、格式塔、篩選三測；5 負空間；6 格線、黃金比例迷思、四個視覺修正；7 縮小、單色、反白三測；8 圖形旁那行名字的字距與字面
- 第三部 練色：9 色相、明度、彩度；10 LOGO 用幾色；11 色彩心理哪些能信、色弱模擬；12 對比值、版本、留白、色號
- 結業：13 十二條檢查表、提案順序、崧淳圖形標十步作業
- 附錄：名詞中英對照、延伸閱讀、佐證不足清單

## 證據

- 外部來源（Rand、Bierut、Haviv、Scher、Geismar、Airey、Albers、WCAG 等）都只讀到搜尋摘要：雲端網路擋設計網站，原文逐字未讀。每處標〔搜尋摘要〕，附錄 C 列出佐證不足的說法。
- 〔實測〕是白澤自己算或畫的：崧淳四色的 L*、C*、WCAG 對比、色弱模擬（colour-tool）；16／32／64 px 縮小圖；思源黑體「上國小口」字面框。
- 圖全部是白澤自繪；練習用形狀和「示例工程」都不是 LOGO 提案，也沒有第三方標誌或照片。
