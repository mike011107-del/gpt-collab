〔圖：sc2.jpg〕

### 工程黃：從照片量出來的車身色
**#D68702** CMYK 15/53/100/2 Pantone 131 C 附近（色差 0.9） RAL 1006 附近（色差 3.1）
過去幾份文件裡出現過四個黃：#D68702、#D58401、#F3B51B、#FACA30。前兩個都是從車身照片量的（不同天、不同照片），差 1.0，看不出來；後兩個跟車身差 13.7 和 19.5，是不同的黃。**本報告一律用 #D68702。**
照片量的顏色受光線影響。做招牌、印刷前，要拿車身的實際烤漆跟色票本比對一次。

### 這代表什麼
- 車身顏色不改，所以主色只能出現在標誌、招牌、文件、制服、網站，以及車上的標誌位置。
- 黃車在台灣路上不稀奇（第 5 頁），單靠黃色認不出是崧淳。讓人記住的工作要交給主色和標誌。
- 工程黃上面放白字只有 2.87，太淡；放墨色字有 5.05，夠清楚。車身上的字要用深色。

涵蓋英、德、法、日、美、澳等地的環境集團、水務、清管、管線修復與設備廠。從標誌檔、官網與車隊照片量色。

### 看到的規律
- 48 家有 23 家只用一個彩色加黑白灰，例如 Veolia 的紅、Biffa 的紅、Lanes 的粉紅。
- 有彩色主色的 42 家中，紅占 11 家。台灣同業沒有紅，國外常見。
- 深青附近（#0C424A 色差 15 以內）國外沒有品牌；最近的是 Ventia 16.7。

- 這 48 家是大品牌，不代表各國所有小型清管公司。
- 取色來自網頁與照片，跟印刷色票會有落差。
- 國外沒人用的顏色，不代表在台灣也沒人用：深青在國外是空的，在台灣有華通衛生行的 #005959（第 11 頁）。

## 到了工地，多半穿橘或螢光黃反光衣，品牌靠背上和胸前的標誌
〔圖：Kier_c08.jpg〕
Kier（英國營造）：螢光黃反光背心，背後大字標誌。
〔圖：Remondis_c04.jpg〕
REMONDIS（德國）：橘色反光工作服。
〔圖：Tideway_c05.jpg〕
Tideway（倫敦下水道隧道）：橘、青綠兩色反光衣。

- 主色選得太淺或太鮮，印在反光布上會跟底色搶；兩個候選都是深色，這點應該都沒問題（推論）。

# 四 好的企業識別怎麼管顏色

## 大公司的手冊都規定：同一個畫面只用少數幾個顏色
〔圖：veolia_p7_palette.jpg〕
Veolia 品牌手冊色彩頁：紅、白、黑固定；同一頁建議最多兩色，可另加黑白。
〔圖：nasa_colour.jpg〕
NASA 1975 年手冊：只有 NASA 紅、NASA 暖灰兩色。
〔圖：epa_agency.jpg〕
美國環保署 1977 年手冊：機關色（EPA 藍、綠）與各業務色分兩層。

### 從這些手冊整理出的四條原則
1. **一個主色就夠。**國外大品牌與台灣同業，都約一半只用一個顏色加黑白。
2. **大面積用白，主色是重點，不是背景。**建議書的參考比例是白 60、主色 25、灰 10、黃 5（第 16 頁）。
3. **顏色要先定色號，再定用法。**手冊都把 Pantone、CMYK、RGB 與「不准怎麼用」寫清楚。
4. **車身顏色不改也能成套。**NASA 1975 只管標誌的位置、大小與黑白反轉。崧淳可以照這個做法，只規定車門標誌與車身字的位置和大小。

# 五 輔色：工程黃

## 工程黃已定，用法要先講好：黃底配深字，不要配白字
深青 #0C424A 亮度比 3.87 看起來多亮 59.0
靛藍 #333D66 亮度比 3.66 看起來多亮 58.7
白 #FFFFFF 亮度比 2.87 看起來多亮 46.1
中灰 #777777 亮度比 1.56 看起來多亮 55.1
黑 #000000 亮度比 7.33 看起來多亮 61.0
同一個工程黃放在五種底上。「看起來多亮」是色彩模型（CIECAM02）的預測值，數字越大越亮；模型不算色相偏移。
| 組合 | 亮度比 | 可以做什麼 |
|---|---|---|
| 墨色字 #222B2C 在工程黃上 | 5.05 | 車身文字、黃底告示，內文也可以 |
| 白字在工程黃上 | 2.87 | 不夠，避免 |
| 工程黃在深青上 | 3.87 | 大字、線條、色塊；小字不行 |
| 工程黃在靛藍上 | 3.66 | 大字、線條、色塊；小字不行 |
| 工程黃在深青的深階上 | 5.50 | 可以放小字 |
| 工程黃在靛藍的深階上 | 5.60 | 可以放小字 |

- 工程黃當輔色時面積要小：一條線、一個重點框、車身本身。印刷品上不要整面鋪黃。
- 放在深色底上，黃看起來會比在白底上更亮（模型預測：深青底 59.0、靛藍底 58.7、白底 46.1）。
- 推論：深青底會讓黃略偏紅橘，靛藍底會讓黃略偏黃；偏多少這個模型算不出來，要看實物。

# 九 使用原則

## 選定主色後，照這幾條用

### 面積比例（參考）
白 60、主色 25、灰 10、工程黃 5。這是建議書提的起點，不是規定；車身不在此限。

### 文字
- 白底上的字：主色或墨色。
- 主色底上的字：白。
- 工程黃底上的字：墨色，不用白。
- 工程黃當字：只在主色深階上，或當大標題。

### 車身
- 車身黃不改。車門放「標誌＋公司名」的小字，車廂或罐體放大字名稱，兩層大小差 2.5 到 7 倍（國內外公務車照片估的量級）。
- 遠看的字高：每 1 公分字高，理想狀況約可在 3.6 公尺外讀到（美國招牌協會 USSC 平均值）；開車時至少打六五折，約 2.3 公尺。例如要在 50 公尺外讀到，字高約 22 公分。
- 黃車身上用深色字；反白字只放在另外加的主色色塊裡。

### 不要做的事
- 不要同時用深青和靛藍。選定一個，另一個就不用了。
- 不要把主色調亮、調鮮來「更醒目」；要醒目時用工程黃當小面積重點。
- 不要在主色上加漸層、陰影、發光。我們看到的大品牌手冊多是平塗。

# 十 宣傳語候選

## 四句候選，尚未定案
條件：句中要有「崧淳」（可以拆開放在上下句）；一聽就知道是做清淤或管線檢視；要對仗或有反差；不要套話。
崧淳把淤泥全帶走，把裂縫全留下。
主推。前半講清淤，後半講 CCTV 檢視：裂縫一條不漏留在影片和報告裡。念到「裂縫全留下」會愣一下，想一下才懂。風險：可能被誤讀成「不修裂縫」，用在名片時下面要接公司全名和業務。
電影一鏡到底，為了拿獎；崧淳一鏡到底，為了驗收。
國土署的 CCTV 規範要求檢視連續、不得中斷或剪接。同一個「一鏡到底」，電影拿來炫技，這行是規範。句子長，適合投標簡報、影片片頭。
崧淳天天下水，從不拖人下水。
前面是真的下到下水道，後面是把人拖下水。對象是發包的承辦人（推論）。句子短，適合名片和車尾。
淤泥要灌水才崧，報告不灌水才淳。
崧、淳拆開的版本。「灌水」轉兩個意思：前面是真的沖水，淤泥才鬆；後面是數字不灌水，報告才純。崧念鬆、淳念純，兩句句尾合起來就是崧淳。要念出聲才聽得出諧音，印出來第一次看可能會卡一下。
從 30 句中選出。篩選只做過內部一輪；上網查重有做，但範圍有限；還沒有給外部的人試聽。

# 十一 標誌與標準字的設計原則

## 主色定了以後，標誌照這幾條做
這一頁是從國內外的研究、設計大師作品與企業手冊整理的原則。不是標誌設計稿。
1. **圖形要跟公司名一起出現。**新品牌還沒人認得，單獨一個圖形記不住；圖加名字比只有其中一樣好（Bresciani 與 Del Ponte，2017）。
2. **要不要畫出行業，看客人認不認得你。**讓人一看就知道賣什麼的標誌，對陌生品牌較有利（Luffarelli 等，2019）。但同一研究也發現，行業本身讓人聯想到不舒服的東西時，畫出來反而扣分。清淤可能讓人想到污泥（推論：研究沒有測過清淤業），所以「做什麼」可以交給字（例如「下水道清淤・CCTV 檢視」），圖形不一定要畫管子和水滴。
3. **一個標誌只用一個構成想法。**1960 到 80 年代的經典標誌 38 個裡有 33 個如此；台日公部門標誌也多半如此。
4. **避免太細的線和縫。**比標誌寬度 1/14 還細的線或縫，縮到網站小圖示（約 16 像素）時會消失；名片、車門這種尺寸還沒有測過。
5. **中文標準字要逐字調。**直接打字型會有字重、字寬不一的問題。「崧」是上下結構、「淳」是左右結構，並排時重心與寬度不同，要個別修。字形要原創或有授權，不直接用電腦字型當標準字。
6. **不建議用 AI 生成標誌。**AI 圖形難以逐筆修改，著作權歸屬也還有爭議，容易跟現有圖形相似（推論）。

台灣 21 家同業裡，畫水滴水波、管子的有 8 家（第 4 頁）。崧淳若也這樣畫，會跟同業擠在一起。

# 附錄

## 方法、限制與出處

### 怎麼量的
- 色差用 CIEDE2000，亮度比用 WCAG 2，都用同一支程式算，數字可重算。
- 標誌與車身顏色從圖片量：去背後統計面積，取主要顏色。照片受光線、壓縮影響，誤差可能有數個色差單位。
- CMYK 用 Ghostscript 的一般印刷描述檔換算；Pantone 用公開的 Pantone Coated 色表（npm pantonr 0.1.0）、RAL 用 RAL Classic 色表（npm ral-colors 1.0.1）找最近一號。都不是官方色票。
- Munsell、色彩模型與研究文獻的計算資料可以另外提供。

### 這份報告的範圍與限制
- 台灣同業 21 家、國外 48 家，取自公開網頁、商標資料與業主提供的資料夾，不是全部同業。
- 這次也上網查了崧淳本身、台灣下水道 CCTV 與清淤業者、近年水務與營造業的品牌改版：沒有找到崧淳的公開資料（新設立）；找到的改版案例（例如德國營造 Diker Bau 用青綠配紅，weandthecolor.com 報導）沒有改變本報告的結論。
- 候選色只在螢幕上比較過，還沒有實體打樣。
- 宣傳語沒有做過外部試聽。
