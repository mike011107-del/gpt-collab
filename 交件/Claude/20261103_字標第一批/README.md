# 崧淳字標　第一批（黑白，三個骨架方向）

2026-11-03。梁特助 14:02「你要去查找相關資源替我設計阿!!!!」後交件。照 `.claude/skills/logo-design-logic` 第五步做，這一批只用來挑骨架，不是定稿。

| 方向 | 骨架 | 收筆 | 共同細節 |
|---|---|---|---|
| W1 黑體・切角 | 思源黑體 Black | 所有外角切同一個斜角（字高 1000 時切角 24） | 崧：山的中豎高出約 6% |
| W2 明體 | 思源宋體 Bold | 沿用明體收筆 | 同上 |
| W3 楷書・延續車身 | 霞鶩文楷 Medium，每邊加粗 18 | 沿用楷書收筆 | 同上 |

- 檔案：`崧淳_字標第一批_20261103.pdf`（6 頁 A5）、`SVG/`（字標、原字型對照、全名組合、反白組合）。
- 字形來源是 SIL OFL 1.1 開源字型（授權檔在 `程式/`），OFL 允許修改與做 logo；要註冊商標前請律師看。
- 檢查：字寫對、收筆一套規則、反白修細、不用說明也成立，三個都過；16px 時 W2 橫筆變淡；跟台灣同行字標並排還沒比對；逐字精修等方向挑定後做。
- 重建：`程式/build_wm.py <輸出資料夾> x` 產生 SVG，`程式/page_wm.py <輸出資料夾> <Noto Sans TC fontsource package>` 產生 HTML，再用 `交件/Claude/20261103_LOGO設計原則統整/程式/pdf.js` 印成 PDF。字型檔路徑寫在 `程式/design.py`（`../fontsrc/`）。
