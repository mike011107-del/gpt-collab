## 八件事

1. **最常見的配色是一個顏色加黑白灰。** 48 家有 23 家這樣做，另有 7 家只用同一色系的深淺。
2. **用兩個顏色的，會把兩色的深淺拉開。** 19 個多色 logo，明度差（ΔL*）中位數 32，13 個在 26 以上（68%）。隨機配兩個彩色，中位數 20、38%；同業 logo 色打亂重配，中位數 17、32%。例外是 Kier，紅和藍綠的明度差約 1，轉黑白就糊掉。樣本只有 19 個。
3. **橘、黃反光衣是全行業共用的。** 121 張照片裡有人的約 71 張，約 55 張穿橘或螢光黃反光衣，跟公司主色無關（目視計數）。反光橘 OKLCH 色相 38 到 55，反光黃 117 到 123，車身工程黃 #D68702 在中間（69）。工程黃跟最近的反光橘（SUEZ、Clancy）差約 11（ΔE2000）。
4. **顏色要叫得出名字，才容易被記住。** 見下方「叫得出名字嗎」。
5. **遠看先丟掉顏色，明暗留得最久。** 見下方「越遠，越看不出顏色」。
6. **印在一般紙上，深色會變淺、變灰。** 見下方「印在紙上」。
7. **好的識別先有一件公司自己的事，再用一個顏色長年講它。** Vattenfall、Caterpillar、Veolia、Siemens 都是這樣。
8. **標誌只放一個想法，整套識別靠寫成數字的規則。** 這是美感串量出來的結論。

## 一、八種配色方式

48 家國外同業 logo 主色分組（色相差 45° 以內算同色系，45° 到 90° 算相鄰，90° 以上算對比）：

| 方式 | 家數 |
|---|---|
| 一個彩色加黑白灰 | 23 |
| 同一色系深淺 | 7 |
| 相鄰色 | 3 |
| 兩色對比 | 8 |
| 四色 | 1（Watercare） |
| 只有黑白灰 | 6 |

1. **一個顏色用到底**（Biffa 紅、Kanal-Türpe 橘）。最省事、最好記。代價是這個顏色要一個人撐起大面積、小字、遠看、印紙所有場合。
2. **同一色系深淺**（Scottish Water、Insituform、Tideway）。深的寫字，淺的當底或點綴。Veolia 手冊規定主色只能調成 70%、50%、30%。
3. **相鄰色**（Sydney Water、Uisce Éireann、PUB）。藍配藍綠是水務最常見的做法，很難配錯，代價是三家擺一起很難分。
4. **兩色對比**（SUEZ、Metro Rod、Roto-Rooter、Clancy）。幾乎都是一深一亮：深色寫字，亮色做點。研究（Schloss 與 Palmer 2011，整理稿）把「兩色好不好看」拆成三件事：色相相近整組較和諧；色相差大前面的圖形較跳；明暗差兩邊都有影響。
5. **色相環公式**（互補、分裂互補、三角、類似）。48 家沒有一家照三角或四角配。色相環只告訴你用哪幾個色相，不告訴你深淺和比例。互補色要用感知色彩空間（OKLCH）算：工程黃 #D68702 的正對面是 OKLCH 249° 的藍，不是紫。
6. **依性格配色**。同一色相，調明暗和濃淡氣質就換了。先決定「鮮、深、灰、淺」哪一種，再選色相。同業主色多落在「深」和「鮮」（目視歸納）。橘黃調深就變褐色，暗黃、褐色是人最不喜歡的顏色之一（Palmer 與 Schloss 2010，摘要）。定位：折扣、速食多用最鮮的原色；高價品牌多用低彩度配一個克制的重點色（單一來源，只當線索）。
7. **比例：誰當主角**。60-30-10 是常見經驗法則。Thames Water 白色領頭、藍只在 logo 和字；Biffa 紅色領頭、白只在字。Vattenfall 把白色放第一位。Veolia 色盤除了紅白黑還有 14 色，但同一畫面建議最多兩色，可另加黑白。
8. **招牌色加上共用的訊號色**。暖色訊號色說「這裡在施工」，不說「這是哪一家」。Romaniuk：跟別人共用的元素比較弱。另一種做法是把招牌色做進制服（メタウォーター藍、KAISER 深藍、Roto-Rooter 藍條紋、Tideway 橘青綠）。

**Veolia 手冊（原文已讀）**
- logo 永遠是紅，白、黑只在合作案等非用不可的場合例外；不准用紅以外的顏色或別的字體。
- 主色「適合放字，保證好讀」，淺色「不保證好讀」。色票本身就分好能不能放字。
- 每色給四套數字：Pantone、CMYK（印刷）、RGB、HEX（螢幕）。
- 標誌和名字不能拆開；四周留白等於字母 V 的寬度；橫式為主。

## 二、設計理念

1. **一個顏色講一件公司自己的事。** Vattenfall：藍是水和天空、黃是太陽，2018 年改版前調查 3000 多人，發現舊顏色跟同業分不開（10-16 筆記）。Caterpillar：黃色是為了讓道路工地被看見（10-13 筆記）。Veolia：紅色雙圓是一個人抱住地球（原文已讀）。站得住的理由是公司自己的目標或工作需要；拿名字做文字遊戲（「崧」有山、「淳」有水）不是公司的事。
2. **跟同業反著走。** 48 家裡 23 家 logo 主色是藍（10-17 國外同業報告把紫藍也算進去是 26 家）。Lanes Group 粉紅、Metro Rod 綠，整套用到底。但空位要付代價：沒人用的顏色常常有原因。
3. **長年用同一個精確的顏色。** Tiffany、Caterpillar、John Deere、DHL 幾十年不換。Romaniuk：品牌資產建立期間不要一直改。記憶會把顏色拉向類別中心（Bae 等人 2015，摘要），卡在兩類中間的顏色容易被記成旁邊的典型色，要靠專屬名字和長期一致補回。
4. **標誌只放一個想法（美感串）。** Logo Archive 38 個 1960–80 年代標誌，33 個只用一個構成方法；沒有一個疊三樣東西。
5. **外框和細線（美感串）。** 外框不會讓標誌縮小更好認，只會長得跟別人一樣（擁擠度 0.62 對 0.46）。細於標誌寬度約 1/14 的線，16px 時會消失（Spearman −0.83）。量測只是及格線，好不好看還是要看圖。
6. **整套識別靠規則（美感串）。** NASA 1975 手冊第 7.6 頁：車色不改，靠位置、尺寸、明暗反轉的規則串成一套。
7. **組合方式要限定（美感串）。** British Rail 只准四種排法、紅黑白三色。
8. **公用事業十年改版方向（美感串）。** 13 組裡比較一致的只有拿掉飛線、斜體、照片效果；圖形去留沒有一致方向。
9. **交件版面的 AI 感（美感串）。** 米色底 #F4F1EA、間隔號、拉開字距是 AI 樣子。這份報告改用白底。

## 三、我自己量出來的

### 1. 叫得出名字嗎

中文用 uwdata 多語色名資料，取 OKLab 最近 60 筆回答；英文用 c3 模型。都是網路問卷，受試者沒有分台灣、中國，不是真人辨識測試。

| 顏色 | 中文最多人歸的色系 | 英文 |
|---|---|---|
| 深青 #0C424A | 綠 38%、藍 38%、黑 10%（墨綠色 20%、深藍色 15%） | 38% 叫藍綠 |
| 靛藍 #333D66 | 藍 68% | 79% 叫藍 |
| 工程黃 #D68702 | 黃 52%、橙 40%（土黃色 32%） | 74% 叫橙 |
| 華通衛生行 #005959 | 綠 50% | 54% 叫藍綠 |
| Siemens 石油青 #009999 | 藍綠 35% | 70% 叫藍綠 |
| Tiffany 藍 #81D8D0 | 藍 55% | 50% 叫藍 |

基準（中文最多人歸的色系，中位數）：國外同業 42 個彩色 logo 主色 88%；台灣 17 家同業主色 90%；長年單色品牌 12 個 88%；隨機深色彩色（明度 25 到 45）82%。81 個顏色裡，深青的英文色系一致度最低（38%）。

### 2. 越遠，越看不出顏色

S-CIELAB（Zhang 與 Wandell 1996 原始參數）模擬工程黃細線放在四種底色上。14 公尺外（1 公分線約 0.04°），黃線對底的亮度比：

| 底色 | 亮度比 |
|---|---|
| 深青 #0C424A | 3.0 |
| 靛藍 #333D66 | 2.9 |
| 中藍 #2071B5（Vattenfall） | 1.7 |
| 石油青 #009999（Siemens） | 1.2，幾乎消失 |

主色和輔色要靠明暗差分開，不能靠色相差。螢幕模擬，不代表實物。

### 3. 印在紙上

用 FOGRA39L（銅版）、FOGRA47L（非塗佈，TAC 300）推估最接近的印法。

| 顏色 | 非塗佈彩度剩下 | 跟黑字的色差（ΔE2000） | 非塗佈看起來 |
|---|---|---|---|
| 深青 | 44%（18.3 剩 8.0） | 從 12.4 掉到 5.3 | #3C4F4F |
| 靛藍 | 68%（26.4 剩 18.0） | 從 18.3 掉到 15.7 | #505371 |
| 工程黃 | 68%（73.2 剩 50.0） | | #D4974F，往土黃偏 |
| 華通 #005959 | 61% | 從 19.4 掉到 13.8 | |
| Vattenfall 藍 | 76% | | |

非塗佈紙最深約印到明度 27（模型推估），比深青、靛藍本身還淺。所以手冊要寫兩套印刷色（銅版 Pantone C、非塗佈 Pantone U），各自打樣確認。這是模型推估，正式定色要實體印樣。

### 4. 其他研究（只讀到摘要或整理稿）

- 面積越大看起來越亮、越鮮（CIE 208:2014）。小色票選的顏色刷成整面牆會比預期搶眼。
- 冷色那一邊分得比較粗（Koenderink 等人 2026 預印本）：冷色之間要拉更大的差距才看得出不同。
