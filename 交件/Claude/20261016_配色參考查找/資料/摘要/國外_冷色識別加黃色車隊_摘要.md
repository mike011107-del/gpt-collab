# A1 摘要：冷色企業＋黃色車隊（21 例）

**事實**
- 黃色多是現場功能色：法國郵政為能見度改黃車；Volvo 塗黃為區分農機；NEXCO 企業色綠、橘、藍，巡邏車都黃。
- 冷色多放 logo：小松藍 logo＋黃機身＋藍條紋；Michelin 藍為主，黃只用於按鈕。
- 官方完整色碼只有巴西郵政、Michelin。

**推論**
- 黃色是業界共用色，辨識靠冷色 logo 與條紋。
- 深藍＋黃已被 IKEA、Lidl 等佔走。

**色碼僅 C 級**：小松、Volvo、柳工、西班牙郵政、義大利郵政、DHL、瑞士郵政、ANWB、Vattenfall、IKEA、Ryanair、Lidl、Best Buy。無色碼：New Holland、NEXCO。
